# Política de privacidade — SGP OS Compactas

Este site está pronto para publicar a política na web, por exemplo pelo GitHub Pages.

1. Crie um repositório público separado (ex.: `sgp-os-compactas-privacidade`).
2. Envie `index.html` para a raiz.
3. Em Settings → Pages, selecione Deploy from a branch, `main` e `/(root)`.
4. Depois de publicado, copie a URL pública e informe essa URL na seção de privacidade do Microsoft Partner Center.

Revise a política e inclua um canal de contato válido antes de publicar, se quiser fornecer contato direto. Não publique credenciais nem dados reais de clientes.
